Explainer

Don’t draw it. Run it.

Name an idea from computer science. Explainer builds a small, working copy of it and turns the run into a lesson you can play, rewind and break.

/plugin install explainer --marketplace irfanalimd/explainer
mapreduce · this page Real run · deterministic

01Why

A drawing of a system can be wrong for years and nobody notices. A program that runs can’t get away with that.

So Explainer doesn’t draw. It writes a tiny version of the real thing. MapReduce really counts the words. Raft really elects a leader. Every event in that run becomes a step on screen, and every number you see came out of it.

Then it teaches the way a patient teacher would. You meet the problem before the fix, one idea at a time. Right before the interesting part, the page stops and asks what you think happens next, and a wrong guess plays out for real.

02How it works

  1. 01

    You name the idea

    /explainer consistent hashing, or whatever has been bugging you.

  2. 02

    It builds a small, real version

    A short simulation of the system. Each message, vote and count on the page is something that code actually did.

  3. 03

    Agents write the lesson. Others check it.

    One writes the steps at three levels, from new to expert. Others review them blind, against the run and the sources.

  4. 04

    You get one page

    Play it, pause it, turn the knobs. Share a link to an exact moment, or teach a room from it in presenter mode.

04Install

One line in Claude Code, then ask.

/plugin install explainer --marketplace irfanalimd/explainer

Then type /explainer and the idea. You’ll want Node 20.10+ and Chrome for its checks. Prefer the skills CLI? npx skills add irfanalimd/explainer -g -a claude-code works too, and the README has the rest.

01 Why

A diagram of a system can be wrong for years, and nobody notices.

So Explainer builds the thing instead, at a small scale. MapReduce really counts the words. Raft really elects a leader. Each event in that run becomes a step on screen, and every number you see came out of it.

Then it teaches the run the way a good teacher would. You meet the problem before the fix, and right before the interesting part the page stops to ask what you think happens next.

On every page

  • Three levels, new to expert
  • A question at the key moment
  • Rewind and replay
  • Links to any moment
  • Presenter mode
  • Light and dark
  • Phones
  • Cited sources

03 How it works

One command, one page

Run it in Claude Code, from any folder.

/explainer <idea>

/explainer the event loop

What happens

Between the command and the page.

  • It checks your machine first: Node, Chrome, and whether the browser can draw with WebGPU or WebGL 2.
  • It writes a small simulation of the real thing, so each message, vote and count on the page is something that code did.
  • One agent writes the lesson at three levels, and others review it blind, against the run and its sources.
  • It hands you one HTML file that opens offline, straight from file://.
  • Claude Code
  • Node 20.10+
  • Chrome for checks
  • No npm install
